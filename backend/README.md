# Backend

The backend is the FastAPI application for CivicFix.

## Main Responsibilities

- Report submission.
- Report retrieval.
- Report status updates.
- Department assignment.
- AI analysis orchestration.
- Duplicate detection.
- Geospatial search.
- Notification triggering.
- Admin dashboard APIs.
