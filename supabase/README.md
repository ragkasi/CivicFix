# Supabase

Supabase is used for CivicFix database, auth, storage, realtime updates, PostGIS, and pgvector.

## Supabase Responsibilities

- Store reports.
- Store departments.
- Store AI analysis.
- Store report images.
- Store embeddings.
- Store duplicate suggestions.
- Store status history.
- Support admin and resident authentication.
- Support realtime dashboard updates.

## Required Extensions

postgis
vector
uuid-ossp
