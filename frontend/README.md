# Frontend

The frontend is the Next.js / React application for CivicFix.

## Main Areas

Resident portal
Admin dashboard
Map interface
Report tracking page

## Key Features

- Resident report form.
- Image upload.
- Location picker.
- Admin report table.
- Admin map.
- Report detail panel.
- AI summary display.
- Duplicate suggestions.
- Status workflow.
- Realtime dashboard updates.
