# MCP Server

This folder contains the planned city-ops-mcp server for CivicFix.

## Purpose

The MCP server exposes reusable city operations tools that can classify reports, route them to departments, detect duplicates, summarize neighborhood issues, and generate resident-facing updates.

## Server Name

city-ops-mcp

## Planned Tools

classify_report
route_to_department
generate_resolution_update
detect_duplicate_reports
summarize_neighborhood_issues
get_report_context
