# Demo Script

## Scenario

A resident sees a flooded sidewalk near a bus stop after rain.

## Demo Steps

1. Open resident report page.
2. Upload example flooded sidewalk image.
3. Enter description: `This keeps happening near the bus stop after rain.`
4. Drop map pin near a sample location.
5. Submit report.
6. Show AI-generated result:
   - Category: Drainage/Flooding
   - Severity: High
   - Department: Public Works
   - Summary: recurring sidewalk flooding near bus stop
   - Recommended action: inspection request
7. Open admin dashboard.
8. Show report appearing on map.
9. Open report detail view.
10. Show duplicate candidates and nearby reports.
11. Assign to Public Works.
12. Change status to In Progress.
13. Open resident tracking page.
14. Show updated status.
15. Generate resident-friendly update.

## Demo Talking Points

- CivicFix solves a real routing and triage problem for local governments.
- AI does not replace admin judgment; it accelerates classification and prioritization.
- PostGIS enables real geospatial workflows.
- pgvector enables duplicate detection across vague natural-language reports.
- Supabase Realtime makes the admin dashboard operationally useful.
- MCP tools allow city operations workflows to be automated by AI agents.
