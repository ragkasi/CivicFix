# Plan Feature Command

Use this command when planning a new CivicFix feature.

## Prompt

Plan the requested CivicFix feature as a vertical slice. Include:

1. User story
2. Data model changes
3. API endpoints
4. Frontend pages/components
5. Backend services
6. AI/MCP impact if any
7. Tests
8. Rollout order
9. Risks and edge cases

Keep the plan practical and aligned with `CLAUDE.md`.
