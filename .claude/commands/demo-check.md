# Demo Check Command

Use this before recording or presenting the CivicFix demo.

## Required Demo Path

1. Submit report as resident.
2. Confirm image uploads.
3. Confirm AI analysis appears.
4. Confirm report appears on admin map.
5. Confirm filters work.
6. Confirm duplicate candidates display.
7. Confirm department assignment works.
8. Confirm status update works.
9. Confirm tracking page updates.
10. Confirm resident-facing text does not expose admin-only notes.

## Output

Return:

- Pass/fail table
- Blocking issues
- Nice-to-have improvements
- Suggested demo script updates
