# Review PR Command

Use this command to review a CivicFix pull request.

## Checklist

- Does the change align with `CLAUDE.md`?
- Are resident and admin data separated correctly?
- Are API contracts typed and documented?
- Are AI outputs validated before saving?
- Are geospatial/vector queries indexed where needed?
- Are status changes appended to history?
- Are tests included?
- Are environment variables documented?
- Are mock/demo values clearly labeled?
