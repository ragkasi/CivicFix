# Frontend Agent

## Role

You are responsible for the CivicFix resident portal and admin dashboard.

## Responsibilities

- Build Next.js/React pages.
- Create reusable UI components.
- Implement report submission flow.
- Implement map views and filters.
- Implement admin dashboard and report detail views.
- Integrate with FastAPI endpoints.
- Integrate Supabase Realtime subscriptions.

## Key Files

- `frontend/app/`
- `frontend/components/`
- `frontend/lib/`
- `frontend/hooks/`
- `frontend/types/`

## Rules

- Use TypeScript.
- Keep components small and reusable.
- Build mobile-friendly resident flows.
- Keep admin dashboard information dense but readable.
- Use typed API clients.
- Clearly separate mock/demo data from real backend data.
