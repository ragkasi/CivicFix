# Skill: Civic Demo Readiness

## Purpose

Make sure CivicFix is ready for a strong portfolio demo.

## Demo Must Show

- Resident submits a report.
- Report includes image, text, and location.
- AI classifies the issue.
- AI estimates severity.
- AI recommends a department.
- Admin sees report in dashboard.
- Admin sees report on map.
- Admin views possible duplicate suggestions.
- Admin updates status.
- Resident sees updated status.

## Demo Quality Checklist

- No broken links.
- No empty dashboard.
- Seed data exists.
- Map loads correctly.
- Report form has validation.
- AI outputs are visibly labeled.
- Status workflow works.
- README explains the project clearly.
- Demo script is easy to follow.

## Rules

- Prioritize demo clarity over unnecessary complexity.
- Mock only what must be mocked.
- Mark mock data clearly.
- Make the project feel deployable and realistic.
