# Hook: Frontend Check

## Purpose

Define the checks that should run before accepting frontend changes.

## Future Checks

Run frontend formatter.
Run frontend linter.
Run TypeScript checks.
Run frontend tests if configured.
Verify production build works.

## Required Focus Areas

- Resident report form.
- Admin dashboard.
- Map rendering.
- Report detail panel.
- Status badges.
- AI summary display.
- Error and loading states.

## Expected Result

Frontend changes should not break the main demo flow.
