# Claude Hooks

This folder documents useful checks that should eventually be implemented as scripts.

At this stage, do not create actual hook scripts unless requested.

The goal is to define what the hooks should verify once the codebase exists.

## Planned Hooks

backend-check
frontend-check
demo-check

## Hook Principles

- Hooks should catch obvious issues before commits.
- Hooks should not be overly slow.
- Hooks should be easy to run locally.
- Hooks should support the main demo flow.
