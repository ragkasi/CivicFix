# Hook: Backend Check

## Purpose

Define the checks that should run before accepting backend changes.

## Future Checks

Run backend formatter.
Run backend linter.
Run backend type checks if configured.
Run backend tests.
Verify required environment variables are documented.
Verify FastAPI app starts successfully.

## Required Focus Areas

- Report creation.
- Report retrieval.
- Status updates.
- Department assignment.
- AI analysis mocking.
- Duplicate detection mocking.
- Supabase connection safety.

## Expected Result

Backend changes should not break the main report intake and admin workflow.
